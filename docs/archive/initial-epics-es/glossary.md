# Glosario / Glossary

| Término (ES)                | Term (EN)                 | Descripción                                                                 |
|-----------------------------|---------------------------|-----------------------------------------------------------------------------|
| PMO                         | PMO                       | Project Management Office - Oficina de gestión de proyectos                |
| Portafolio                  | Portfolio                 | Conjunto de todos los programas y proyectos gestionados                    |
| Programa                    | Program                   | Agrupación de proyectos con objetivos estratégicos comunes                 |
| Proyecto                    | Project                   | Esfuerzo temporal para crear un producto, servicio o resultado único       |
| Solicitud de proyecto       | Project Request           | Formulario para someter una iniciativa a aprobación                        |
| Folio                       | Reference Number          | Identificador único generado automáticamente                                |
| Fase                        | Phase                     | Etapa del ciclo de vida del proyecto (Planificación, Ejecución, etc.)      |
| Riesgo                      | Risk                      | Evento incierto que puede afectar los objetivos del proyecto               |
| Incidencia                  | Issue                     | Problema o situación que requiere resolución                                |
| AID                         | AID                       | Acción, Incidencia, Decisión - tipos de registros de seguimiento           |
| Cambio                      | Change Request             | Solicitud formal para modificar alcance, tiempo o costo                    |
| Lección aprendida           | Lesson Learned             | Conocimiento adquirido durante la ejecución del proyecto                   |
| Minuta                      | Meeting Minutes            | Registro de una reunión con acuerdos y compromisos                         |
| Organización                | Organization               | Empresa, compañía o cliente para quien se ejecutan proyectos               |
| Unidad de negocio           | Business Unit              | División organizacional dentro de una empresa                              |
| Lineamiento estratégico     | Strategic Alignment        | Objetivo estratégico al que contribuye la iniciativa                       |
| Patrocinador/Sponsor        | Sponsor                    | Persona que provee recursos y apoyo ejecutivo al proyecto                  |
| Semáforo                    | Health Indicator           | Indicador visual: Verde (sano), Amarillo (atención), Rojo (crítico)       |
| Avance                      | Progress                   | Porcentaje de completitud del proyecto                                     |
| Presupuesto                 | Budget                     | Recursos financieros asignados al proyecto                                 |
| Rol                         | Role                       | Perfil de permisos asignable a usuarios                                    |
| Permiso                     | Permission                 | Autorización para ejecutar una acción específica en el sistema             |
| Soft delete                 | Soft delete                | Eliminación lógica (marcar como inactivo sin borrar de la BD)              |
| JWT                         | JWT                        | JSON Web Token - mecanismo de autenticación                                |
| i18n                        | i18n                       | Internacionalización - soporte para múltiples idiomas                      |
